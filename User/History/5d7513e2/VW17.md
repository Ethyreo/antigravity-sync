### Script Implementation
#### [NEW] `/Users/gurman/Coding Projects/PDF_Watermarker/watermark.py`
This script will:
- Accept a source directory containing the PDFs and a `watermark.pdf`.
- Iterate through all `.pdf` files in the source directory.
- Open each target PDF and the watermark PDF using `pypdf`.
- Overlay the first page of the watermark onto **every page** of each target PDF (using `over=True`).
- Implement error handling (`try-except` blocks) to skip and log password-protected or corrupted PDFs.
- Use `tqdm` to display a progress bar in the terminal.
- Save the watermarked files into a newly created `Watermarked_Results_<timestamp>` directory.
