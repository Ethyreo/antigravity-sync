# Bored Games
**Flutter-iOS-Android-App-for-Games-Bored-Games**

A comprehensive multi-game platform built with Flutter.

### Included Games
- **Tic Tac Toe:** Classic unbeatable AI
- **Neon Snake:** Classic snake with glowing graphics
- **Retro Hedgehog:** 8-bit platforming with gravity and collision mechanics
- **Cyber Tetris:** Tile-matching puzzle with a synthwave aesthetic
- **Cyber Minesweeper:** Classic minesweeper logic with neon hazard glows and flag system
