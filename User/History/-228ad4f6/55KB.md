# Build Instructions

## Security & Obfuscation
To ensure the app is secure and difficult to reverse engineer, **ALWAYS** use the obfuscation flags when building for release.

### Android
```bash
flutter build appbundle --obfuscate --split-debug-info=./debug-info
```

### iOS
```bash
flutter build ipa --obfuscate --split-debug-info=./debug-info
```

## Permissions
- **Android**: `INTERNET` permission is enabled for AdTech readiness.
- **iOS**: No capability restrictions currently active.

## Verification
- **High Scores**: Stored with a SHA-256 checksum. Manually editing the `shared_preferences` XML/plist file will cause the score to reset to 0 on next load.
