# Futuristic Nature Dashboard Redesign

The objective is to replace the current default dark-mode Apple-inspired Streamlit UI in the PDF Watermarker project with a **Very Futuristic and Minimalistic** dashboard heavily inspired by **Nature**.

## Proposed Changes

### PDF Watermarker UI Redesign
We will comprehensively overhaul the CSS inside `app.py` to inject a Neo-Nature Glassmorphism aesthetic into Streamlit.

#### [MODIFY] [app.py](file:///Users/gurman/Coding%20Projects/PDF_Watermarker/app.py)

- **Color Palette:**
  - Background: Deep, dark forest black/green (`#040f0a` or radially gradient background mimicking a digital forest).
  - Text: Soothing pale mint (`#e0f2eb`).
  - Accents & Glow: Bioluminescent neon green or teal (`#00ffa3`).
- **Glassmorphism Typography & Layout:**
  - Headers and text will employ minimalistic, clean sans-serif typography with slight text-shadow tracking.
  - Cards and file upload dropzones (`stFileUploadDropzone`) will use heavily blurred backgrounds `rgba(0, 255, 163, 0.03)` with thin neon borders and backdrop-filters (Glassmorphism).
- **Interactive Elements:**
  - Buttons will feature a dark base with a neon green/teal glowing hover effect.
  - Tab navigation will be styled as seamless minimal pills with futuristic glowing underlines for the active tab.

## Verification Plan

### Automated/Local Tests
- **UI Validation Run**: Run the app locally via `streamlit run app.py`. Use the browser to ensure the CSS injection correctly targets Streamlit's new React-based CSS classes (like `stFileUploadDropzone`, `stButton`, `stTabs`).
- **Core Functionality Verification**: Ensure the core features (Watermarking, Splitting, Converting) remain perfectly functional and the UI components correctly load files, show spinners with new themes, and return ZIP downloads.

### Manual Verification
- The end-user can verify the UI by interacting with the app at `http://localhost:8501`. They should check the aesthetic of the tab transitions, the hover glows on the CTA buttons, and the glassmorphism dropzones.
